# NarcoCalc GitLab Redirect

Diese Seite leitet automatisch zur neuen GitHub Pages Seite weiter.

## Projekt umgezogen

NarcoCalc wurde von GitLab zu GitHub migriert.

**Alte URL:** https://peuqui.gitlab.io/narcocalc  
**Neue URL:** https://peuqui.github.io/NarcoCalc

## Deployment

Diese Redirect-Seite wird automatisch über GitLab CI/CD deployed.

Um die Weiterleitung zu aktivieren:
1. Pushen Sie den `gitlab-redirect` Ordner zu Ihrem GitLab Repository
2. GitLab Pages wird automatisch die index.html bereitstellen
3. Besucher werden nach 5 Sekunden weitergeleitet
